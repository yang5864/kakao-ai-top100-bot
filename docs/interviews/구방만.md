최종 status: 질문 수 40/100 (11:50 기준, 이후 질문 1건 추가로 41), 발굴률 46% (4% → 25% → 29% → 38% → 42% → 46%). 코디네이터 지침에 따라 문서 내용은 재질문하지 않고 URL만 기록.

## 사실
- 구방만은 교동 출하장에서 상자를 받아 집하 스캔·등록하고 간선으로 인계하는 일을 맡음 (근거: 기억, "교동 출하장에서 상자를 받아 등록하고 다음 구간으로 넘기는 일")
- 집하 시각 기준은 스캔 기록 시각. 인계했다고 말한 시각과 스캔 기록이 다르면 스캔이 기준 (근거: 기억, "인계했다고 말한 시각과 스캔 기록이 다르면 스캔이 기준입니다")
- 집하 마감 시각, 마감 이후 들어온 박스 처리, 간선 차량 인계 시각, 차를 놓친 상자 처리, 직접 가져오는 고객 접수 시간·장소 규칙, 송장 작성 주체는 정해진 것이 없거나 모른다고 함. 출고 일정은 이민준 운영자와 맞춰 처리 (근거: 기억)
- 송장 등록 뒤 고객 조회에 뜨기까지 3~5시간 걸림. 그 사이 조회가 안 되는 것은 정상이니 고객에게 먼저 송장이 등록된 지 얼마나 됐는지 확인하라고 함 (근거: 기억, "송장 등록 뒤 조회에 뜨기까지 3~5시간 정도 걸립니다")
- 5시간이 지나도 조회가 안 될 때 안내 기준, 이 숫자가 문서 기준인지 경험인지는 모른다고 함 (근거: 기억)
- 파손 발견 시 처리 순서, 사진 각도·장수 기준은 정해진 것 없음. 파손 확인 시 상자 상태와 인수 시각은 자기 스캔 기록으로 답할 수 있음. 파손·분실 처리와 사진 보관은 고객 응대 쪽(이민준 운영자) 담당 (근거: 기억)
- 배송지 변경·취소: 조합몰 주문은 물건을 집하하기 전에는 배송지 변경과 취소가 되고, 집하한 뒤에는 둘 다 안 됨. 반송돼 다시 보내는 물건의 배송지는 집하 뒤라도 배송지 변경 요청으로 받음 (근거: 기억, "제가 아는 범위는 이렇습니다")
- 출하장에서 송장을 직접 고칠 수 있는지, 반송 상자 보관 기간, 재발송 비용·기한·절차, 반송 상자가 출하장으로 되돌아오는지는 모름. 돌아와 직접 인수하면 인수 시각은 자기 스캔 기록으로 말할 수 있으나 다시 스캔하는지는 확실히 모른다고 함 (근거: 기억)
- 합배송은 상온 농산과 냉장·냉동 상품은 보관 조건이 달라 제한됨. 두 상자에 다른 종류 상품이 들어 있으면 같이 묶기 어려움. 출하장에서 상자를 나눠 처리하는지, 송장을 몇 장 찍는지는 모름 (근거: 기억)
