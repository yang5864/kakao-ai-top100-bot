# 이민준

- 개정 1(차액 보상): 06-15 개정으로 범위가 좁아졌다. 개정 전에는 차액 보상이 상담사 재량이었고, 개정 후에는 구매 후 7일 이내, 동일 SKU, 쿠폰 보상으로만 한정. 보상 쿠폰은 CARE3000, CARE5000, CARE10000 중에 차액 이상이 되는 최소 금액 한 장을 발급하고, 발급일부터 90일간 쓸 수 있다. 부칙은 주문 시점 기준: 06-15 전에 주문한 건은 개정 전 규정인 구판을 적용 (근거: 기억, 개정 내용 설명)
