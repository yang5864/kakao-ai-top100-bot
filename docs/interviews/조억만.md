# 조억만
최종 status: 마지막으로 읽은 값은 질문수 33/100, 지식발굴율 55%. 이후 질문수 36/100 시점 status를 보냈으나 발굴률 숫자는 화면에서 확인 못 함(문서 링크 2개 확보로 올랐을 가능성). 추이: 11문 9%, 17문 27%, 20문 36%, 24문 55%, 29문 55%, 33문 55%. 실제 질문은 약 38개, 종료 사유는 24문 이후 발굴률 정체와 인물이 기억 위주로 모른다고 반복하는 포화.

## 사실
- 조억만은 개장 초부터 조합물에서 물건을 사 온 단골. 시작은 지인 소개, 이후 마을 사람들과 거래가 이어짐 (근거: 기억, "처음 물건을 받아 먹기 시작한 건 지인 소개 때문")
- 개장 초부터 이용했지만 가입 환영 혜택을 받은 기억은 뚜렷하지 않음 (근거: 기억)
- 05-09에 조합물에서 산 물건 값이 내려 차액 3,000원을 돌려받음. 규정을 대면 안 된다 하지 않고 상담 직원이 알아서 처리해줌. 가장 고마웠던 응대. 상하거나 깨진 물건 건이 아님, 배송 문제도 아님 (근거: 기억, "상담하는 사람이 알아서 처리해줬습니다")
- 차액 환급 조건은 이후 까다로워졌다고 "들었다": 이제는 기간이 정해졌고, 같은 물건이어야 하며, 차액은 돈이 아니라 쿠폰으로 준다. 산 물건의 하자 접수를 언제까지 해야 하는지도 바뀌었고 "전보다 늘어난 쪽". 구체 일수(차액 신청 기간, 하자 신고 기간 예전/지금)는 못 들었다고 함. 05-09 때와 지금 조건이 같다고 말하기 어렵다고 함 (근거: 풍문. 출처가 상담원/이웃/공지 중 무엇인지, 시기도 기억 못 함)
- 차액 보상과 하자 접수 기한이 예전과 지금 어떻게 다르고 언제부터 바뀌었는지는 개정 이력 문서에 적혀 있다고 안내. 본인은 구판 때 겪은 것만 알고 정확한 조문과 시행일은 모름 (근거: 기억, "날짜나 기간 같은 숫자는 이 자료에서 직접 확인")
- 조합물 회원으로 등록하면 다시 살 때 5% 쿠폰이 나온다고 들음. 더 사면 단골가가 따로 있다고도 들음 (근거: 풍문, "제가 들은 내용은 이 두 가지가 전부예요")
- 쿠폰 자동 적용 여부, 최소 주문금액, 유효기간, 단골가 조건, 회원 등급 이름/기준/혜택은 모름 (근거: 기억)
- 조합물에서 살 때마다 적립금이 조금씩 붙고 오래 두면 없어진다고 들음. 적립률, 소멸 기간은 모름. 탈퇴하면 쿠폰과 적립금이 사라진다고 들음. 모두 직접 확인한 것 아니고 "그렇다더라" 수준 (근거: 풍문)
- 회원 약관에 회원 혜택과 등급, 추천 리워드 지급 조건, 적립, 탈퇴 방법이 적혀 있다고 알고 있음. 구체 조건은 모름 (근거: 기억)
- 추천 리워드는 본인이 받은 기억 없음. 소개해 준 지인이 받았는지도 모름 (근거: 기억)
- 휴면 계정 기간, 탈퇴 후 재가입 제한은 들은 적 없음 (근거: 기억)
- 회원가입 순서, 인증 메일/문자 여부, 입력 제한 시간, 재발송 경험: 기억 안 남. 가입 때 쓴 휴대폰/계정 연결 기록을 보라고 권함 (근거: 기억)
- 로그인 실패, 비밀번호 잠금/재설정, 모바일 앱 접속 경험: 기억 안 남. 평소 조합물에 들어가 물건을 고르고 주문하던 쪽 (근거: 기억)
- 소셜 로그인 사용 여부: 기억 안 남 (근거: 기억)
- 마을 사람들의 로그인/비밀번호 문제 얘기 들은 적 없음 (근거: 기억)
- 주소 변경, 선물 배송: 선물은 가족 모임·지인에게 자주 보냈으나 받는 분 주소로 직접 보냈는지, 포장·메시지 카드, 추가 비용은 기억 없음. 주소 변경 상담과 본인 확인 질문도 기억 없음 (근거: 기억)
- 정기배송 이용 경험과 이웃에게 들은 얘기 모두 없음 (근거: 기억)
- 사칭 문자·전화 받은 기억 없음. 비밀번호/인증번호를 알려 달라는 사람은 직원이라도 믿지 말라는 안내를 들은 기억도 없음 (근거: 기억)
- 배송비, 무료배송 기준, 도서산간 추가비 들은 적 없음. 주문 후 배송 소요일은 평균이라 하면 어림짐작 정도로 숫자 못 줌. 배송 지연·오배송 기억 없음 (근거: 기억)

- 불편했던 응대 기억 없음. 장사를 오래 해서 성의 없는 대응에 예민한 편이라고 함 (근거: 기억)
