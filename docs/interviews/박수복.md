# 박수복
최종 status: 질문 31/100 (31개 시점 발굴률은 알림 토스트에 가려 못 읽음). 이력: 5/100 12%, 20/100 44%, 29/100 53%
## 사실
- 06-25~27 폭우로 수박이 열과 발생. 06-18에 결제된 수박 예약분 10통 중 정상 규격은 6통, 4통은 열과로 규격 미달이라 발송 안 함 (근거: 문서 기반 답변, "열과가 나서 정상 규격은 6통뿐이오")
- 열과 4통은 07-01 이후 다음 수확분으로 채우거나 부분환불. 어느 쪽으로 할지는 박수복이 정하지 않고 주문한 고객이 고르는 것 (근거: 답변 원문)
- 일반 판매 재고는 예약분과 별개 (근거: 답변)
- 6월 초 태풍 1회. 애플망고 예약분은 태풍 오기 전 수확·포장 완료, 그러나 배·항공이 끊겨 송장만 등록된 채 산지에서 냉장 상태로 며칠 대기. 재배 하우스는 멀쩡, 노지 재배분만 상해 쓰러진 것은 폐기. 택배 간선 운송이 재개된 날은 일요일이라 집하는 다음 영업일부터 (근거: 답변, 정확한 날짜는 작황·재해 기록 참조하라 함)
- 작황 확인 날짜는 교동마을 작황·재해 기록, 결항 통보와 집하 재개 시각은 구방만 기사의 시원배송 결항·집하 기록에 있음 (근거: 답변)
- 수산물 조업/입고는 작황·재해 기록에 없음. 홍이장 소관 (근거: 답변)
- 6월 말 품목 구성은 농산 시즌 캘린더 기준 (수박, 하우스감귤, 노지감귤, 만감류, 애플망고, 멜론, 봄감자, 고구마, 참다래, 절임배추, 청귤 예약 라인). 갈치·옥돔 성어기와 냉동 공급은 홍이장 쪽 자료 (근거: 문서)
- 품목별 SKU 카탈로그: 품목, 규격, 등급, 판매 상태, SKU 코드 규칙, 당도보장 표기 방식이 있고, 표기 중량을 어떻게 적는지는 카탈로그 참조. 수산은 홍이장 소관 (근거: 문서)
- 라벨 실물: 수박·감자 같은 농산 라벨 사진, 표기 누락 감귤 구판 예시, 라벨 확인 안내문 포함. 주문 시 표기와 대조하는 방법, 권장 섭취기한·보관기간 확인법 있음. 알레르기/원산지 표기는 라벨 자료에서 직접 확인하라 함. 갈치·옥돔 라벨은 홍이장 소관 (근거: 문서)
- 로트·출고 검사 기록: 로트번호 체계, 출고 전 잰 당도·중량·품온, 주문·포장·배송 이어짐, 조회 규약 포함. 곰팡이·파손 신고 건수는 박수복 기억에 없고 티켓 원문을 세어 로트 기록과 대조해야 함. 농산 쪽까지만 알고 냉동 상품은 박민아 소관 (근거: 문서)
- 상품 상세페이지(스펙·보관법·배송 안내) 문서는 박수복 보유 아님. 상품 소개 글이랑 배송 안내 문구는 홍보 쪽(홍보라) 소관, 공개 문안도 홍보라가 맡음. 박수복은 보관법·상품 특성 등 농사 쪽에서 아는 것만 설명 가능 (근거: 답변)
- 농가 이야기: 재배 농가 스토리 자료가 있음. 어느 농가가 무엇을 어떻게 키우는지 소개하는 공개 카피와 생산자 정보를 어디까지 공개하는지가 적혀 있음. 농가 실명 전부, 연락처, 주소는 공개하지 않음. 손님과 농가를 직접 이어 주는 일도 하지 않음. 농가 소개 원자료는 박수복이 드렸고 손님이 읽을 문안은 홍보라가 만듦 (근거: 문서/답변)
- 박스 동봉 안내문: 박수복은 아는 바 없음. 상자에 넣을 글은 홍보 쪽 소관. 포장한 물건을 싣고 가는 건 구방만 기사 (근거: 답변). 밭에서 딴 물건을 재서 상자에 담아 내보내는 것까지가 박수복 일
- 달력/날씨 이력: 별도 문서 없음, 작황·재해 기록이 날짜별 기상 이력 대신. 예보 시점에 아직 확인하지 못한 상태는 그대로 남아 있음 (근거: 답변)
- 06-18 교동마을 집중호우 때문에 수박 예약분 수확과 선별이 2~3일 밀렸음. 06-25~27 폭우(열과 발생)와는 별개 건. 밀린 예약분 통수는 문서에 없고 박수복도 모름 (근거: 답변 "두 건은 따로 보셔야 하오", "통수는 짐작해서 말하지 않겠소")
- 6월 말 정체전선이 올라와 비가 사흘쯤 이어짐. 비가 많고 해가 모자라 애플망고 숙도·당도 진행이 늦어져 예약 출고가 밀렸고 하우스감귤은 영향 없음. 전선이 물러가 숙도는 회복 중이나 애플망고 예약분 출고 재개 시점은 아직 못 정함. 06-30 현재 기상 특이사항 없이 산지 작업 정상 (근거: 답변)
- 애플망고 하우스 2동은 방제 약 안전사용기간이 안 지나 06-30 현재 수확 불가. 06-21 정기 방제 약 안전사용기간 14일, 06-26 정기 방제 약 안전사용기간 7일. 두 번 다 반영해야 함 (근거: 방제일지 문서 기반 답변). 계산상 06-21+14일=07-05, 06-26+7일=07-03이므로 늦은 쪽 07-05 이후 수확 가능으로 보이나 박수복은 날짜를 짚어 말하지 않음(추정)
- 방제 때문에 생긴 지연과 작황이 늦어서 생긴 지연은 원인이 달라 안내 방식이 다름. 방제 지연은 방제일지와 안전수확 안내를 확인하고, 해당 구역에 방제가 여러 번이면 이력을 모두 적용해 안전수확 가능일과 잔여일 계산, 수확 가능일 확인 뒤 이민준 쪽 영업일·공휴일 달력으로 출고 가능한 날 확인 (근거: 답변)
- "농약 언제 쳤냐"는 질문에 기억으로 날짜를 말하지 말고 방제일지에서 해당 구역 방제 이력을 찾아 자료에 적힌 고객 안내 범위 안에서 답할 것 (근거: 답변)
- 당도 보장: 수박 당도선별 라인 11브릭스 이상 보장, 하우스감귤 12브릭스 이상. 당도 보장 표기가 없는 라인은 애초에 약속한 수치가 없음. 로트 기록의 당도가 낮게 나와도 그것만으로 하자 판정 안 됨 (근거: 답변)
- 당도는 당도계로 재고 무게는 저울로 잼. 수박을 몇 통에 한 번 재는지, 속살 어느 부위를 재는지는 기억이 불확실해 말하지 않음, 로트 출고 검사 기록을 보라 함 (근거: 답변)
- 수박 속이 갈라진 것이 열과인지 정상 공동과·씨 주변 빈 공간인지 구분하는 기준은 박수복이 확실히 말할 수 없음. 겉으로 속을 알 수 없고 추측하지 않음. 하자인지 아닌지 정하는 것은 판매하는 쪽 (근거: 답변)
- 수박·멜론 그물 갈라짐, 노란 땅자국이 하자인지: 박수복이 직접 보고 판단한 적 없어 정상이라 짐작해 말하지 않음. 고객에게 "정상입니다"라고 안내하는 것도 판매 쪽 일이므로 이민준 운영자에게 물으라 함 (근거: 답변)
- 감자: 빛을 보면 초록이 돌고 싹이 남. 껍질이 푸르스름하면 빛을 받아 초록이 돈 것이라 그 부위는 떼고 먹어야 하고, 떼어 낼 부위가 넓으면 먹지 않는 게 맞음. 초록이 돈 부위와 싹의 독성은 가열해도 없어지지 않으니 익혀도 괜찮다고 하면 안 됨. 감자와 고구마는 냉장고에 넣으면 안 되고 빛을 막고 서늘한 상온에 두고 통풍시켜 두라 함 (근거: 답변, 농사 쪽 지식)
- 고구마에서 끈적한 꿀이 나오는 것은 박수복이 아는 얘기가 아니라 짐작해 말하지 않음. 고구마는 최덕만 품목이니 그쪽에 물어보라 함 (근거: 답변)
- 하자인지 정상인지는 박수복이 정할 일이 아니고 파는 쪽이 정할 일 (근거: 답변)
- 감귤 곰팡이 원인이나 수확 후 며칠 지나 생기는지는 기억에 없고 짐작해 말하지 않음. 감귤은 문귀남 소관이라 문귀남에게 물으라 함. 곰팡이 든 물건이 어느 로트였는지는 로트 출고 검사 기록에서 출고 전 잰 값과 대조, 신고 티켓을 세어 로트 기록과 맞춰 볼 것 (근거: 답변)
- 06-30 기준 어느 품목이 문제 있고 정상인지 박수복이 전부 알지 못함. 수박과 멜론만 말할 수 있음. 하동철은 과수, 문귀남은 감귤, 최덕만은 저장 발작물을 하니 해당 사람에게 직접 들어 보라 함 (근거: 답변)
- 멜론 상태는 기억으로 "정상이오" 하거나 "호우 영향 있었소" 하고 짚어 말하면 틀릴 수 있으니 작황·재해 기록의 날짜별 기상·피해·숙도·수확 지연 기록으로 확인하라 함 (근거: 답변)
- 고객이 호우 때 출고된 수박 도착이 늦었다고 하면: 산지 쪽에서 볼 수 있는 건 작황·재해 기록뿐. 배송 중 어디서 늦어졌는지는 박수복이 본 일이 아니라 짐작해 말하지 않음. 출고한 뒤 도착이 늦어진 구간은 구방만 기사 쪽에 문의 (근거: 답변)
- 생산자 분담: 최덕만은 감자·고구마·절임배추, 하동철은 애플망고·참다래, 박수복은 수박·멜론, 문귀남은 하우스감귤·노지감귤·만감류 (근거: 답변)

- 하우스감귤 방제: 06-13 정기 방제, 안전하게 수확 가능한 날은 06-27, 지금(06-30) 딸 수 있음. 수박 방제 기록은 박수복 기억에 없어 방제일지에서 직접 확인. 안전수확 가능일이 지나도 수확 가능일 확인 뒤 이민준 쪽 영업일·공휴일 달력으로 출고 가능한 날을 따로 확인 (근거: 답변)
